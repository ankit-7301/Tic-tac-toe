# Tic Tac Toe Game

A simple **Tic Tac Toe** game built using **HTML, CSS, and JavaScript** for two players.

## Features

* Two-player gameplay using X and O.
* Automatically checks for winning combinations.
* Detects draw games.
* New Game and Reset Game buttons.
* Responsive and simple UI.

## Technologies

* HTML
* CSS
* JavaScript
